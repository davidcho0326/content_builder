# 전략실컷빌더 (Strategy Cut Builder)

> 전사 브랜드(DUVETICA, MLB, DISCOVERY) 대상 AI 컨텐츠 생성 시스템.
> 브랜드 DNA + 외부 트렌드 믹싱 → 인플루언서/셀럽/에디토리얼 컷 대량 생성.

## 프로젝트 구조

| 경로 | 역할 |
|------|------|
| `brand-dna/schema.json` | DNA 키값 구조 정의 (전 브랜드 공통) |
| `brand-dna/{brand}.json` | 브랜드별 DNA 데이터 |
| `plan.md` | 실행 플랜 |

## 실행 순서

1. 브랜드 DNA 정리 (레퍼런스 + 기획팀 자료 → JSON)
2. 제품 이미지 확보 (공식몰/촬영본)
3. DNA + 제품 + 레퍼런스 → 기존 스킬로 컷 생성
4. 결과물 큐레이션 → 보고용 셀렉

## 사용 스킬 (기존 FNF Studio)

| 컷 유형 | 스킬 | 인풋 |
|---------|------|------|
| 인플루언서 시안 | AI인플루언서 / 셀카 | 제품 이미지 + 캐릭터 |
| 셀럽/화보 컷 | 브랜드컷 / 에디토리얼 | 제품 이미지 + 모델 |
| 레퍼런스 기반 | 레퍼런스브랜드컷 | 레퍼런스 + 제품 + 모델 |
| 제품 연출 | 제품연출 | 제품 이미지 |
| 배경 변형 | 배경교체 | 생성된 컷 + 배경 디렉션 |
