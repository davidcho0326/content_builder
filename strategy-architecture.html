01 / Overview

What It Does

이 에이전트가 뭘 하는 거야?

경쟁사/트렌드 마케팅 이미지를 수집하고, 우리 브랜드 DNA와 매칭하여 적합한 이미지를 선별한 뒤, 우리 브랜드 스타일(옷/컬러/소재)로 변환하여 캠페인/인플 이미지를 대량 생성합니다. 패션 에디토리얼 수준의 퀄리티를, 프롬프트 텍스트만으로 만들어 냅니다.

이 DNA 구조가 연결에서 왜 중요한가

기획팀의 DNA 전략과 자사몰+인스타 231장 실측 분석을 결합하여 이미지 생성에 최적화된 DNA 가드레일을 구축했습니다.

나중에 트렌드 에이전트가 연결되면: 이 가드레일 수치를 트렌드 데이터로 자동 업데이트합니다. 구조만 맞으면 — data_driven_guardrails.{category}.attributes.{속성}.min/max/median — 누가 만들든 우리 파이프라인이 작동합니다.

즉, 이 DNA JSON이 "하네스" — 앞단(트렌드/디자인)과 뒷단(캠페인/리테일)을 연결하는 표준 인터페이스입니다. PM이 다른 에이전트를 연결할 때, 그 에이전트의 output이 이 JSON 구조에 맞기만 하면 됩니다.

03 / Generation

How It Generates

이미지는 어떻게 생성해?

레퍼런스 이미지를 직접 AI에 넘기는 게 아닙니다. VLM이 "촬영 감독 지시서"로 변환하고, DNA를 블렌딩하고, Anti-AI 기법을 주입한 뒤 프롬프트 텍스트만으로 생성합니다.

STEP 1
트렌드 마케팅컷를 참조로 직접 첨부
라이프스타일 비전 이미지를 VLM이 초정밀 분석합니다. 포즈, 카메라, 라이팅, 컬러 그레이딩, 불완전함까지 — 8개 항목을 "촬영 감독 지시서" 수준으로 추출합니다.
STEP 2
DNA에서 옷/컬러/소재 자동 블렌딩
추출된 지시서에 brand-dna.json의 제품 속성(소재, 컬러, 패턴, 핏)을 덮어씌웁니다. 레퍼런스의 구도/무드는 유지하면서 옷/컬러/소재만 우리 브랜드 DNA로 교체하는 원리입니다.
STEP 3
Anti-AI 프롬프트 주입
"~하는 순간을 포착" (Captured Moment), Hasselblad 500CM + Kodak Portra 400 필름 스펙, 바람에 흩날리는 머리카락 같은 자연스러운 불완전함을 프롬프트에 주입합니다. 이게 없으면 "AI가 만든 티"가 납니다.
STEP 4
3모델 병렬 생성
동일 프롬프트로 Gemini, GPT Image 2, Higgsfield 3개 모델이 동시에 이미지를 생성합니다. 각 모델의 강점이 다르므로, 비교 후 베스트를 셀렉합니다.
Higgsfield MCP 연결 방법

Higgsfield는 MCP(Model Context Protocol) 서버로 연결합니다. 프로젝트 루트의 .mcp.json에 아래를 추가하세요.

{ "higgsfield": { "command": "npx", "args": ["-y", "mcp-remote", "https://mcp.higgsfield.ai/mcp"] } }

첫 연결 시 브라우저 OAuth 로그인이 필요합니다.
추천 모델: soul_2 (패션 에디토리얼) / nano_banana_2 (최고 퀄리티 4K)

04 / Output

Output Structure

결과물은 어떻게 나와?

모든 결과물은 타임스탬프 폴더 안에 정리됩니다. 각 씬별로 3모델 비교가 가능하고, 사용된 프롬프트와 설정이 함께 저장됩니다.

{timestamp}_{type}/
WJ_01_gemini.png ← Gemini 결과
WJ_01_gpt.png ← GPT 결과
WJ_01_higgsfield.png ← Higgsfield 결과
WJ_01_00_reference.jpg ← 트렌드 마케팅컷 원본
WJ_01_prompt.txt ← 사용된 프롬프트
config.json ← 생성 설정 (비율, 모델, DNA 버전)
포맷
PNG, 3:4 세로형
비교
씬별 3모델 비교
검수
7-Gate 자동 Pass/Fail
자동 검수

inspect_results.py로 7-Gate 자동 검수를 실행할 수 있습니다. 브랜드 DNA 대비 컬러 일치도, 모델 비율, 의류 디테일, 배경 적합성 등을 자동으로 pass/fail 판정합니다.

05 / Input Contract

Input Requirements

앞 에이전트한테 뭘 받아야 해?

이 에이전트에 넘겨줄 인풋의 명세입니다. 필수 항목이 없으면 자체 대안(Plan B)이 있는 경우도 있지만, 트렌드 마케팅컷는 반드시 필요합니다. (AI 자동 셀렉 또는 수동 큐레이션)

인풋 형식 필수? 없으면?
brand-dna.json JSON 선택 자체 크롤링 + VLM 분석으로 자동 생성
트렌드 마케팅컷 폴더 이미지 7~15장 필수 Plan A: AI 자동 셀렉 / Plan B: 수동 선택
시즌 / 카테고리 텍스트 필수 사용자가 지정 (예: "27SS WJ")
제품 이미지 이미지 폴더 선택 DNA에서 제품 속성 자동 참조

이 에이전트가 생산하는 결과물 목록입니다. 뒷단 에이전트(컨텐츠 기획안, 채널배너 등)가 이 아웃풋을 바로 받아서 사용합니다.
